# 今天吃什么

两人晚饭用的渐进式网页应用（PWA）。手机优先，也能在电脑浏览器里用。纯静态，没有后端，可以添加到主屏幕。

在线演示：<https://jintian-chi-shenme-public.loyal-tuna-9474.chatgpt.site/#/>

翻分类、看菜、摇一桌、列出要买的东西，再把只属于你们的菜写进账本。四套皮肤可以随时换。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器默认在 [http://127.0.0.1:4321](http://127.0.0.1:4321)。

构建：

```bash
npm run build
```

产物在 `dist/`。预览构建结果：

```bash
npm run preview
```

## 部署

`npm run build` 之后，把 `dist/` 整份丢到 GitHub Pages 或任意静态托管即可。

资源使用相对路径，路由是 hash（`/#/list` 这种），所以项目页子路径也不用再配 404 回退。可以「添加到主屏幕」，带了 manifest 和 service worker。

## 四套皮肤

右上角四个色点，或「我们」页里切换。选择记在这台浏览器的 `localStorage`：

| id | 名字 |
| --- | --- |
| `cafe-journal` | 咖啡馆手账 |
| `kitchen-chalkboard` | 厨房黑板报 |
| `watercolor-market` | 水彩菜市折页 |
| `midnight-magazine` | 午夜食光杂志 |

单独的键是 `jte.theme`，方便刷新前先涂上底色。菜单、账本、想吃、几菜几汤、采购勾选和盒马搜索模板都在 `jte.v1`。换设备不会同步。

## 菜从哪来

`src/data/seed.json` 里有 455 道菜，来自小不点子抖音作品的菜名统计，带分类和样例视频链接。页面按 `category` 分组。

这些数据里没有完整食谱，也没有实拍图。菜谱步骤和食材是按菜名拆出来的家常模板，拿不准的地方标了「待完善」。卡片上的图是画出来的盘子。以后可以再补真正的做法和照片。你们自己的菜写在「我们的账本」，只存在本机。

## 在盒马搜

没有接盒马的私有加购接口，也不会假装能放进购物车。

每一项「在盒马搜」会先复制食材名，再打开一个可配置的搜索链接。默认模板是：

```text
https://www.freshippo.com/?keyword={q}
```

`{q}` 会换成食材名。盒马官网不一定会直接进入搜索结果，所以复制是兜底：打开 App，粘贴即可。模板在「我们」页修改，也可以改成淘宝网页搜索，那只是公开搜索，不是盒马加购。
